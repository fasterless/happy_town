# 邻里小镇 MVP 🏡

一个完整的经营类游戏单页应用，包含农场、家园、好友、社区等多个系统。

## 🎮 游戏特色

### 核心玩法循环
**种植 → 收获 → 完成订单 → 升级 → 解锁新内容**

- 🌾 **农场系统**：种植5种作物（小麦、番茄、草莓、玉米、南瓜）
- 📋 **订单系统**：完成6种不同类型的订单获取金币和经验
- 🏠 **家园系统**：购买和摆放8种家具装饰你的房间
- 👥 **好友系统**：与5个NPC好友互动（拜访、点赞）
- ⛲ **社区系统**：5阶段喷泉建设，捐献资源共建小镇
- 🛍️ **商城系统**：购买礼包、月卡、钻石和家具套装
- ✅ **任务系统**：7种每日任务 + 5档活跃度宝箱
- 📊 **后台管理**：查看用户数据、埋点统计、配置信息

## 🚀 快速开始

### 方法1：直接打开（推荐）
直接在浏览器中打开 `index.html` 文件即可游玩

python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (需要先安装 http-server)
npx http-server

http://localhost:8000

## 🎯 游戏系统详解

### 农场系统
- 6块农田可同时种植
- 作物实时生长，显示剩余时间
- 一键收获所有成熟作物
- 不同作物需要不同等级解锁

### 等级系统
- Lv.1 → Lv.20 共20个等级
- 每个等级解锁新内容
- Lv.5 解锁好友拜访完整功能
- Lv.10 解锁社区系统

### 货币系统
- 🪙 **金币**：购买种子和基础家具
- 💎 **钻石**：购买高级家具和礼包
- 🤝 **友情点**：通过好友互动获得
- 🏅 **社区贡献**：捐献资源获得

### 社区系统
- 5个喷泉建设阶段
- 每个阶段需要不同资源
- 完成阶段获得丰厚奖励
- 社区成员贡献排行

### 每日任务
- 登录游戏
- 收获作物 5 次
- 完成订单 3 次
- 拜访好友 3 次
- 点赞好友 3 次
- 捐献社区资源 1 次
- 购买家具 1 次

### 活跃度宝箱
- 20分：金币 x100
- 40分：友情点 x30
- 60分：钻石 x10
- 80分：木材 x5 + 布料 x5
- 100分：抽奖券 x1

## 🛠️ 技术栈

- **纯原生开发**：HTML5 + CSS3 + JavaScript (ES6+)
- **无依赖**：不需要任何第三方库
- **数据持久化**：localStorage存储游戏进度
- **响应式设计**：适配多种屏幕尺寸

## 🎮 游戏提示

1. **新手引导**：创建角色后，先去农场种小麦
2. **快速升级**：完成镇长早餐篮订单可快速升级
3. **测试功能**：后台管理页面有"发放测试补偿"按钮，可获得大量资源
4. **每日重置**：任务系统会在每日首次登录时自动刷新
5. **月卡机制**：购买月卡后每日可领取钻石和金币

## 🐛 调试功能

在浏览器控制台中可以查看：
- 游戏状态对象：`state`
- localStorage数据：`localStorage.getItem('neighbor-town-mvp-state-v1')`
- 清空进度：`localStorage.clear()` 然后刷新页面

- 用户登录
- 升级
- 购买种子
- 种植作物
- 收获作物
- 完成订单
- 购买家具
- 好友互动
- 社区捐献
- 任务领取
- 商城购买

所有埋点数据可在"后台"页面查看
