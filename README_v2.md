# 邻里小镇 v2.2 🏡

一个完整的经营类游戏单页应用，现已全面升级为模块化架构，新增加工坊、湖畔钓鱼、幸运转盘、季节活动等多个系统。

## 🎮 游戏特色

### 核心玩法循环
**种植 → 收获 → 加工 → 完成订单 → 升级 → 解锁新内容**

### 🌟 v2.2 新增功能
- 🥖 **加工坊**：6 种配方（面包、果酱、薯条、南瓜派…），作物加工成成品，解锁高价订单
- 🎣 **湖畔钓鱼**：每日 5 次免费垂钓，6 种鱼获 + 惊喜掉落，稀有黄金锦鲤
- 🎡 **幸运转盘**：消耗抽奖券，8 格奖池 + 40 抽保底超级大奖
- 🌸 **季节活动**：按现实月份轮换的 5 个限定活动，登录领季节礼物
- 🎁 **邻居回礼**：拜访好友有概率触发邻居的回礼彩蛋（每人每天一次）
- 🐦 **新宠物**：小狐狸（提升钓鱼稀有度）、鹦鹉（加速加工）
- 🌻 **新作物**：向日葵（Lv.9）、葡萄（Lv.11）
- 🪑 **新家具**：书架、壁炉、鱼缸、烤炉、钢琴、秋千椅
- 📋 **新订单**：需要加工成品的特殊/稀有订单（Lv.10+）
- 🏆 **新成就**：垂钓高手、工坊巧匠、小镇锦鲤、人缘之星、铲屎官
- ✅ **每日任务**：新增钓鱼、加工任务和 130 分宝箱
- 🛠️ **修复**：修复了 v2.1 无法启动的崩溃（缺失 import）、假作物订单无法完成等遗留问题

### v2.0 原有功能
- 🏆 **成就系统**：18 种成就，完成获得丰厚奖励
- 🐱 **宠物系统**：7 种可爱宠物，提供不同的游戏buff
- ☀️ **天气系统**：4 种天气影响作物生长和订单奖励
- 🎯 **新手引导**：6 步交互式教程，快速上手
- 🔊 **音效系统**：WebAudio 实时合成音效，沉浸式体验
- 📊 **装饰评分**：房间布局评分系统（F-S 级）
- ✨ **作物生长阶段**：可视化生长过程（种子→幼苗→成长→成熟）
- 🌾 **农场系统**：12 块农田，10 种作物实时种植
- 📋 **订单系统**：14 种订单，完成获得金币和经验
- 🏠 **家园系统**：36 格房间，14 种家具自由摆放
- 👥 **好友系统**：5 个 NPC，拜访点赞互动
- ⛲ **社区系统**：5 阶段喷泉建设，资源捐献
- 🛍️ **商城系统**：10 种商品，月卡充值礼包
- ✅ **任务系统**：9 种任务，6 档活跃度宝箱
- 📊 **后台管理**：数据统计，测试补偿

## 🚀 快速开始

### 方法1：使用开发服务器（推荐）
```bash
# 安装依赖

# 启动开发服务器
npm run dev

# 访问 http://localhost:3000
```

### 方法2：直接打开
双击 `index_v2.html` 文件，浏览器会自动打开游戏

### 方法3：Python 服务器
```bash
python -m http.server 3000
# 访问 http://localhost:3000/index_v2.html
```

## 🎯 游戏系统详解

### 成就系统
- 12种成就类型
- 实时进度追踪
- 完成自动发放奖励
- 成就统计面板

### 宠物系统
- 5种宠物可领养
- 每日喂养互动
- 亲密度影响buff效果
- 不同宠物提供不同加成

### 天气系统
- 每日随机天气
- 晴天/雨天/下雪/彩虹
- 影响作物生长速度
- 特殊天气双倍奖励

### 装饰评分系统
- 基础分：每件家具10分
- 风格一致性加成
- 对称布局加成
- 完美布局加成（填满36格）
- 评级：F/E/D/C/B/A/S

## 🛠️ 技术栈

- **纯原生开发**：HTML5 + CSS3 + ES6+ JavaScript
- **模块化架构**：ES Modules
- **构建工具**：Vite
- **代码规范**：ESLint + Prettier
- **数据持久化**：localStorage
- **响应式设计**：支持多种屏幕尺寸

## 📊 代码统计

- **代码行数**：~6000 行（模块化后）

## 🎮 游戏提示

1. **新手引导**：首次进入会有6步教程
2. **快速升级**：完成"镇长早餐篮"订单可快速升级
3. **测试功能**：后台管理页面有"发放测试补偿"按钮
4. **成就追踪**：查看成就界面了解进度
5. **宠物buff**：Lv.13解锁宠物系统，选择合适的宠物加速游戏进程
6. **天气影响**：留意每日天气，彩虹天气订单奖励翻倍
7. **装饰评分**：追求S级评分解锁"完美家园"成就
8. **月卡机制**：购买月卡后每日可领取钻石和金币
9. **数据保存**：游戏进度自动保存在浏览器localStorage
