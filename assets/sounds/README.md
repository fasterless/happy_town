# 音效文件说明

本目录用于存放游戏音效文件。由于音效文件为二进制文件且较大，这里仅提供占位符。

## 所需音效文件

1. **pop.mp3** - 种植音效（短促的"啵"声）
2. **collect.mp3** - 收获音效（轻快的收集声）
3. **levelup.mp3** - 升级音效（激励性的上升音效）
4. **success.mp3** - 成功音效（愉快的完成声）
5. **coin.mp3** - 金币音效（叮当声）
6. **click.mp3** - 点击音效（轻柔的点击声）

## 获取音效

你可以从以下免费资源网站获取音效：

- **Freesound.org** - https://freesound.org/
- **Zapsplat** - https://www.zapsplat.com/
- **Mixkit** - https://mixkit.co/free-sound-effects/

## 音效要求

- 格式：MP3
- 时长：0.1-2秒
- 音量：适中，不刺耳
- 品质：清晰，无杂音

## 临时方案

如果暂时没有音效文件，游戏会静默运行（音效系统会捕获加载错误并继续运行）。
